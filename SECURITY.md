# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately rather than creating a public GitHub issue or pull request.

Use GitHub's **Report a vulnerability** option in the repository's **Security** tab, if it is available. If private vulnerability reporting is unavailable, contact the repository owner through the contact information on their GitHub profile and provide only the details needed to establish secure communication.

Include, where possible:
- A description of the potential vulnerability and its impact.
- Steps to reproduce it or a minimal proof of concept.
- The affected version, commit, device, or configuration.
- Any suggested mitigation.

Do not include real credentials, personal data, or other users' information in a report.

## What to expect

The maintainer will review the report and, when possible, respond with an acknowledgement and next steps. Please allow reasonable time for investigation and a fix before publicly disclosing the issue. A response or fix timeline is not guaranteed.

## Scope

Report security issues that affect Glassio or code maintained in this repository. For vulnerabilities in third-party services or dependencies, use the relevant project's security reporting process as well.
